HOW TO RUN THE PROJECT FROM SCRATCH
==================================

Project version:
- 0.2.3

This file gives step-by-step commands for a fresh setup.

1. PREREQUISITES
----------------
Install these first:
- Python 3.12
- Node.js 20+
- MongoDB
- Docker Desktop (only if you want the Docker run path)


2. OPEN THE PROJECT
-------------------
Open PowerShell and go to the project root:

```powershell
cd "F:\product search"
```


3. CREATE THE ENV FILE
----------------------
Copy the template:

```powershell
Copy-Item .env.example .env
```

Then edit `.env` and set at least:

```env
GROQ_API_KEY=your_groq_api_key
SERVICE_API_KEY=your_service_api_key
ADMIN_API_KEY=your_admin_api_key
```


4. LOCAL RUN FROM SCRATCH
-------------------------

4.1 Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

4.2 Install Python dependencies:

```powershell
pip install -r requirements.txt
```

4.3 Install frontend dependencies:

```powershell
Set-Location "react UI"
npm install
Set-Location ..
```

4.4 Make sure MongoDB is running.

If MongoDB is installed locally as a Windows service, start it if needed.

4.5 Initialize database indexes:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python jobs\init_db.py
```

4.6 Scrape products:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python jobs\run_scrapper.py --once
```

4.7 Process the scraped data into the app database:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python jobs\run_data_processing.py --with-init-db
```

4.8 Start the full app:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python run_all.py
```

4.9 Open the app:

- Frontend: http://127.0.0.1:5173
- API: http://127.0.0.1:8000
- API docs: http://127.0.0.1:8000/docs


5. DOCKER RUN FROM SCRATCH
--------------------------

5.1 Copy the env file:

```powershell
Copy-Item .env.example .env
```

5.2 Edit `.env` and set:

```env
GROQ_API_KEY=your_groq_api_key
SERVICE_API_KEY=your_service_api_key
ADMIN_API_KEY=your_admin_api_key
```

5.3 Start Docker Desktop.

5.4 Build and start containers:

```powershell
docker compose up --build -d
```

5.5 Open:

- Web UI: http://localhost:3000
- API: http://localhost:8000
- API docs: http://localhost:8000/docs

5.6 Stop containers:

```powershell
docker compose down
```


6. OPTIONAL CHECKS
------------------

Run tests:

```powershell
$env:PYTHONPATH = (Get-Location).Path
pytest -q
```

Run frontend build:

```powershell
Set-Location "react UI"
npm run build
Set-Location ..
```

Run API smoke check:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python jobs\smoke_assistant_api.py --base-url http://127.0.0.1:8000 --service-api-key YOUR_SERVICE_API_KEY --admin-api-key YOUR_ADMIN_API_KEY
```


7. NOTES
--------
- Scraped product data is stored in MongoDB, not inside the delivery ZIP.
- Daraz source ratings now come from real scraped data after running the scrape and processing pipeline.
- Shophive may still show predicted fallback ratings because current live pages do not expose stable rating data in the active scrape path.
- If source ratings are stale after a fresh setup, rerun scrape plus processing so the latest rating fields are populated:

```powershell
$env:PYTHONPATH = (Get-Location).Path
python jobs\ingest_sources.py
python jobs\normalize_offers.py
```
- Seller products and in-app reviews are created through the app after startup.
